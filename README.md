# Лабораторная работа №3 — Адаптивная вёрстка, Flexbox и CSS Grid

## Описание

Страница «О себе» на тему **«Геймер и разработчик игр»** (Вариант 5).

В третьей лабораторной работе добавлены Flexbox и CSS Grid, сделана адаптация под разные устройства, проверена контрастность и использованы семантические теги HTML5.

## Что сделано в лабораторной работе

### 1. Навигационное меню (Flexbox)
- Горизонтальное меню в шапке сайта
- На мобильных устройствах перестраивается в вертикальный список

### 2. Карточки «Любимые жанры игр» (Flexbox)
- 4 карточки с иконкой, названием и кратким описанием
- Каждая карточка обёрнута в тег `<article>`
- На десктопе — 4 карточки в ряд, на планшете — 2, на мобильном — 1

### 3. Дашборд «Статистика игрового времени» (Grid)
- 3 блока: часы в RPG, победы в шутерах, пройденные квесты
- Размечен тегом `<section>`
- На десктопе — 3 колонки, на мобильном — 1 колонка

### 4. Медиа-запросы
- Для планшетов: `max-width: 992px`
- Для мобильных: `max-width: 600px`
- Убрана горизонтальная прокрутка

### 5. Контрастность
- Основные цвета соответствуют требованиям WCAG (контраст ≥ 4.5:1)

## Семантические теги

| Тег         | Назначение                              |
|-------------|-----------------------------------------|
| `<header>`  | Шапка с именем и навигацией             |
| `<nav>`     | Меню навигации                          |
| `<main>`    | Основной контент                        |
| `<article>` | Карточки жанров                         |
| `<section>` | Блоки навыков, статистики, проектов     |
| `<aside>`   | Боковая панель                          |
| `<form>`    | Форма обратной связи                    |
| `<footer>`  | Подвал                                  |
