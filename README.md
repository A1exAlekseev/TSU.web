# Лабораторная работа №4 — Основы JavaScript

## Описание

Страница «О себе» на тему **«Геймер и разработчик игр»** (Вариант 5).

В четвёртой лабораторной работе к странице подключён скрипт `script.js`: ввод и вывод данных, условные конструкции, циклы и функции для работы с массивом.

---

## Данные

Массив из 7 чисел — время, проведённое в разных играх за неделю (в часах):

`[12, 2, 15, 3, 8, 1, 11]`

---

## Что сделано в лабораторной работе

### 1. Ввод/вывод
- `prompt` — запрос имени пользователя (если имя не введено, используется «Геймер»)
- `alert` — приветствие и итоговое сообщение
- `console.log` — дополнительные данные и сообщения

### 2. Функции

| Функция | Назначение |
|---------|------------|
| `findMax(arr)` | Возвращает максимальное значение массива |
| `filterPopularGames(arr)` | Оставляет только игры с временем > 10 часов |
| `calculateSum(arr)` | Возвращает сумму элементов массива |
| `countLightGames(arr)` | Считает «лёгкие» игры (≤ 3 часов) циклом |

### 3. Цикл
- Проход по массиву и подсчёт количества «лёгких» игр (≤ 3 часов)
- Расчёт доли коротких игровых сессий в процентах

### 4. Условные конструкции
- Проверка введённого имени (`null` или пустая строка)
- Если общее время > 25 часов — в консоль выводится сообщение о балансе между играми и учёбой

---

## Вывод результата

| Способ | Что выводится |
|--------|---------------|
| `alert` | «Привет, <имя>! Вы провели X часов в играх, из них Y часов – в самых популярных.» |
| `console.log` | Доля коротких игровых сессий и их количество |
| `console.log` (доп.) | «Возможно, стоит сбалансировать время между играми и учёбой» (если сумма > 25) |

---

## Использованные технологии

- HTML5, CSS3
- JavaScript (`prompt`, `alert`, `console.log`, функции, циклы, условия)
