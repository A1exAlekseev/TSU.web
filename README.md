# Лабораторная работа №5 — DOM и взаимодействие с элементами страницы

## Описание

Страница «О себе» на тему **«Геймер и разработчик игр»** (Вариант 5).

В пятой лабораторной работе реализованы интерактивные функции: динамическое добавление и удаление карточек игр, переключение светлой/тёмной темы, скрытие/показ списка и сохранение состояния через `localStorage`.

---

## Контент

Карточки любимых игр:
- Название
- Жанр
- Рейтинг (1–5, звёзды)
- Кнопка «Удалить» (удаляет конкретную карточку)

---

## Что сделано в лабораторной работе

### 1. Поиск элементов
- `getElementById` — кнопки и контейнер игр
- `querySelector` — секция игр
- `querySelectorAll` — проверка наличия карточек перед удалением

### 2. Манипуляции с DOM
- «Добавить игру» — через `prompt` запрашиваются название, жанр и рейтинг, создаётся карточка (`createElement` + `appendChild`)
- «Удалить последнюю» — удаляет последнюю карточку из массива и перерисовывает список
- Индивидуальная кнопка «Удалить» на каждой карточке
- Переключение темы — добавление/удаление классов `theme-light` / `theme-dark` у `<body>`
- Скрытие/показ — класс `hidden` на контейнере списка игр

### 3. Обработка ошибок
- Перед работой проверяется существование всех необходимых элементов
- Если элемент не найден — сообщение в консоль и выход из функции
- При пустом списке при попытке удалить последнюю игру — `alert` и сообщение в консоль
- Проверка корректности рейтинга (целое число от 1 до 5)
- Наведён порядок в `style.css`

### 4. localStorage
- При добавлении/удалении игр список сохраняется в `localStorage`
- При переключении темы сохраняется выбранная тема
- При загрузке страницы состояние восстанавливается (список игр + тема)

---

## Использованные технологии

- HTML5, CSS3 (переменные, классы темы)
- JavaScript (DOM API, события, `localStorage`)
