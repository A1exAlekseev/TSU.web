## Описание

HTML/CSS-страница «О себе» на тему **«Геймер и разработчик игр»** (Вариант 5).

## Что было добавлено и изменено в Лабораторной работе №2

1. **CSS-переменные (`:root`)**:
   - Основные цвета (тёмно-фиолетовый и неоновый зелёный) вынесены в глобальные свойства.
2. **Интерактивные карточки проектов**:
   - Элементы списка проектов оформлены в виде отдельных блоков-карточек (`.project-card`).
   - Реализован эффект «поднятия» при наведении: `transform: translateY(-5px)` + свечение `box-shadow`.
   - Реализован эффект «вдавливания» при нажатии: `:active { transform: translateY(2px); }`.
3. **Оптимизация формы обратной связи**:
   - Для полей `input` и `textarea` добавлены уникальные `id`.
   - Добавлены теги `<label>` с атрибутом `for` для улучшения доступности.
   - Для `textarea` настроены увеличенные внутренние отступы (`padding: 12px`) и зафиксировано изменение размера по вертикали (`resize: vertical`).
   - Кнопка отправки формы оформлена inline-стилем `style="text-transform: uppercase;"`.
4. **Улучшение HTML-структуры**:
   - Убран лишний `<div>` из контейнера `<main>`.
   - Основной контент сгруппирован в тег `<article>`
5. **Git**
   - Постарался сделать дополнительную ветку в git для данной лабораторной работы.

## Использованные технологии

- **HTML5** — семантическая разметка (`<header>`, `<main>`, `<article>`, `<section>`, `<aside>`, `<form>`, `<label>`, `<footer>`).
- **CSS3** — CSS Custom Properties (`:root`), Grid Layout, Flexbox, псевдоклассы `:hover` и `:active`, CSS-трансформации (`transform`, `box-shadow`).

---

## Семантические теги

| Тег | Назначение |
|-----|-----------|
| `<header>` | Шапка сайта с именем и описанием |
| `<main>` | Главный контейнер с двухколоночной сеткой CSS Grid |
| `<article>` | Левая колонка с основным содержанием |
| `<section>` | Смысловые блоки (навыки, карточки проектов, форма) |
| `<aside>` | Боковая панель (платформы, жанры) |
| `<form>` | Форма обратной связи |
| `<label>` | Связанные текстовые метки для элементов формы |
| `<footer>` | Подвал с копирайтом |
