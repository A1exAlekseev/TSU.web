## Описание

HTML/CSS-страница «О себе» на тему **«Геймер и разработчик игр»** (Вариант 5).  
В рамках лабораторной работы проект был модернизирован и приведён в полное соответствие с требованиями Варианта 5: вынесен внешний CSS, расширены CSS-переменные, настроены типы позиционирования, добавлены новые псевдоклассы и интерактивные состояния элементов.

## Что было добавлено и изменено в Лабораторной работе №2

1. **Вынос CSS во внешний файл (`style.css`)**:
   - Основные стили вынесены во внешний файл `style.css` и подключены через `<link rel="stylesheet" href="style.css">`.
   - Во внутреннем теге `<style>` файла `index.html` оставлено строго одно правило для `textarea`.
2. **Реализация типов позиционирования (`position`)**:
   - **Static**: явным образом задано для тега `<header>`.
   - **Relative**: задано для `.project-card` в качестве контейнера позиционирования.
   - **Absolute**: применимо для плашек-бейдж `.project-badge`, позиционируемых в углу карточек.
3. **Добавление псевдоклассов и интерактивных состояний**:
   - **`:focus`**: стилизован фокус для полей формы (`input:focus`, `textarea:focus`) и кнопки (`button:focus`) с неоновой подсветкой.
   - **`:active`**: добавлено состояние вдавливания при нажатии для кнопки формы (`form button:active`).
4. **Расширение CSS-переменных и оптимизация кода**:
   - Добавлены глобальные переменные для шрифта (`--font-main`) и базовых цветов (`--color-white`, `--color-black`).
   - Устранено дублирование `padding: 8px` у элемента `textarea` — отступы четко разделены между `input` и `textarea`.
5. **Интерактивные карточки проектов**:
   - Элементы списка проектов оформлены в виде отдельных блоков-карточек (`.project-card`).
   - Реализован эффект «поднятия» при наведении: `transform: translateY(-5px)` + свечение `box-shadow`.
   - Реализован эффект «вдавливания» при нажатии: `:active { transform: translateY(2px); }`.
6. **Оптимизация формы обратной связи**:
   - Для полей `input` и `textarea` добавлены уникальные `id`.
   - Добавлены теги `<label>` с атрибутом `for` для улучшения доступности.
7. **Валидация и Git**:
   - Код проверен на валидность HTML5 и CSS3.
   - Изменения зафиксированы в репозитории Git.

## Использованные технологии

- **HTML5** — семантическая разметка (`<header>`, `<main>`, `<article>`, `<section>`, `<aside>`, `<form>`, `<label>`, `<footer>`).
- **CSS3** — CSS Custom Properties (`:root`), Grid Layout, Flexbox, позиционирование (`static`, `relative`, `absolute`), псевдоклассы (`:hover`, `:active`, `:focus`, `:visited`), CSS-трансформации (`transform`, `box-shadow`).

---

## Семантические теги

| Тег | Назначение |
|-----|-----------|
| `<header>` | Шапка сайта с именем и описанием (статическое позиционирование) |
| `<main>` | Главный контейнер с двухколоночной сеткой CSS Grid |
| `<article>` | Левая колонка с основным содержанием |
| `<section>` | Смысловые блоки (навыки, карточки проектов, форма) |
| `<aside>` | Боковая панель (платформы, жанры, внешняя ссылка) |
| `<form>` | Форма обратной связи |
| `<label>` | Связанные текстовые метки для элементов формы |
| `<footer>` | Подвал с копирайтом |
