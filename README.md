## Использованные технологии

- **HTML5** — семантическая разметка (`<header>`, `<main>`, `<section>`, `<aside>`, `<form>`, `<footer>`)
- **CSS3** — стилизация (Flexbox, Grid, цвета, hover-эффекты)

---

## Семантические теги

| Тег | Назначение |
|-----|-----------|
| `<header>` | Шапка с именем и описанием |
| `<main>` | Основной контент страницы |
| `<section>` | Смысловые блоки (навыки, проекты, форма) |
| `<aside>` | Боковая панель (платформа, жанры) |
| `<form>` | Форма обратной связи |
| `<footer>` | Подвал с копирайтом |

---

|------|-----|----------|
